# ZM-14 — Skill Architecture Orientation Map

## Target state

Taxonomy stewards and job architects can understand the complete skill-design structure from a single read-only page before changing governed records. The page explicitly separates:

1. the behavioral orientation layer: **Thought / Results / People / Self → 12 organization-authored navigation clusters → 38 competency references**; and
2. the governed taxonomy layer: **Domain → Group → atomic Skill**.

Links between a competency and a skill are shown as contextual mappings, never as a claim that the KFLA factor structure is the skill taxonomy.

## Functional scope

- Approved records are visible by default; users may opt into `in_review` and `draft` records.
- Factor, cluster, domain and group branches progressively disclose their children.
- Hover and keyboard focus show concise public-safe descriptions; click pins a detail view.
- The detail view exposes identity, lifecycle, behavioral orientation, mapped-job count and governed skill relationships.
- A secure Mermaid diagram is generated from the currently unfolded branches.
- Users may copy the Mermaid source or download it as an `.mmd` file.
- Structural edits are deliberately absent; a direct action opens the governed Taxonomy workbench.

## Security and content boundaries

- Mermaid runs with `securityLevel: strict`; diagram callbacks and embedded HTML are disabled.
- Mermaid source is generated by application code from workspace records, not accepted as executable user input.
- Only public-safe summaries and organization-authored interpretations appear. Licensed definitions remain excluded.
- Archived and retired records never appear.

## Accessibility

- Expand/collapse controls are semantic buttons with `aria-expanded` and `aria-controls`.
- Definitions appear on both pointer hover and keyboard focus.
- The Mermaid graph contains an accessible title and description.
- Selection remains in native React buttons; the SVG is a complementary visualization, not the only way to access information.

## Acceptance criteria

- The page is available as **Architecture map** in Skill Designer.
- Collapsed default view shows all four orientation factors and all approved taxonomy domains.
- Expand all reveals approved factors, clusters, competencies, domains, groups and skills.
- Review/draft toggles never reveal archived or retired records.
- Selecting a competency highlights linked visible skills in the inspector.
- Selecting a skill displays its KFLA context, job-mapping count and governed semantic relationships.
- Mermaid copy/download output matches the current unfolded state and renders without unsafe interaction.
- The production bundle contains no licensed definition text, shared secret or n8n API credential.
- Lint, TypeScript validation and production build pass.

## Research basis

- W3C WAI-ARIA Disclosure Pattern: semantic buttons, `aria-expanded`, Enter and Space activation.
- W3C WAI-ARIA Tree View Pattern: hierarchical orientation and keyboard-operable node concepts.
- Mermaid Flowchart and Accessibility documentation: generated flowcharts, `accTitle`, `accDescr` and strict security boundaries.
